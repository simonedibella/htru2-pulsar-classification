# HTRU2 dataset

`HTRU_2.csv` is the unmodified nine-column, headerless dataset originally supplied through the UCI Machine Learning Repository. It contains eight numeric features and a binary label in the last column (0 = non-pulsar; 1 = pulsar). `HTRU2_original_readme.txt` preserves the original author-supplied description and citation guidance.

**Source:** https://archive.ics.uci.edu/dataset/372/htru2  
**Dataset author:** Robert J. Lyon  
**Dataset DOI:** https://doi.org/10.24432/C5DK6R
